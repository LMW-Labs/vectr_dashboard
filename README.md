# Vectr Dashboard

An internal data intelligence dashboard built on Python and Firebase. Scrapes, processes, and surfaces structured insights from multiple data sources.

## What it does

- Scheduled data collection via `scheduled_scan.py` and `scraper_logic.py`
- AI-assisted analysis and summarization using Claude (`backend.py`)
- Firebase backend for storage and real-time data access
- React frontend dashboard for reviewing processed results

## Stack

| Layer | Tech |
|---|---|
| Backend | Python (FastAPI) |
| AI | Anthropic Claude |
| Storage | Firebase / Firestore |
| Frontend | React |
| Auth | Firebase Auth |
| Deploy | Google Cloud / Firebase Hosting |
